# Subway Runner

A lightweight Subway Surfers-style endless runner built with Three.js.

## Features
- Real GLB character (FoodCourier from Gobkit, CC0) with run animation
- 3-lane movement (swipe or arrow keys)
- Jump over barriers
- Procedural trains & barriers
- Coin collection & score
- Mobile + desktop controls
- Progressive speed

## Controls
- **← →** or **A D** or swipe left/right → change lane
- **↑** or **Space** or swipe up → jump
- Collect gold coins, avoid trains and barriers

## Tech
- Multi-file ES modules
- Three.js r170 via CDN + import maps
- No build step required

## Run locally
Just open `index.html` in a modern browser (or use any static server).
